# Nexcent Landing Page

A modern landing page for a membership management platform, built with pure HTML and CSS.

## Overview

Nexcent is a landing page showcasing membership management solutions for organizations, associations, and clubs. The design features a clean, professional layout with smooth hover animations and a cohesive green-themed color scheme.

## Sections

- **Header** - Sticky navigation with logo, nav links, and account actions
- **Hero** - Main call-to-action with illustration
- **Our Clients** - Client logos showcase
- **Services** - Membership management solutions (3 service cards)
- **Feature** - Company highlights with learn more CTA
- **Products** - Statistics and achievements grid
- **Footer Guide** - Design showcase section
- **Testimonials** - Client feedback with customer logos
- **FAQ** - Blog insights with article cards
- **Get a Demo** - Call-to-action banner
- **Footer** - Links, social media, and newsletter signup

## Technologies Used

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Google Fonts (IBM Plex Sans)
- Font Awesome 6.5.0

## How to Run

Open `index.html` in any modern web browser.
